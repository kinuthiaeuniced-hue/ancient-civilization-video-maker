# The World Before Us — AI Ancient Civilization Video Maker

Version 1 is a static GitHub Pages web app that generates a 20-minute documentary production blueprint for the Kush documentary.

## What it does
- 20-scene structure
- Timing for each scene
- Narration goals
- Visual prompts
- Audio direction
- YouTube title, description opening, keywords and thumbnail concept

## What it does not do yet
It does not directly generate an MP4 or call paid AI APIs. Later versions can connect image/video generation, text-to-speech and automated video assembly.

## GitHub Pages
Set the repository's Pages source to **GitHub Actions**. The included workflow deploys the site whenever `main` is updated, and it can also be run manually from the Actions tab.
